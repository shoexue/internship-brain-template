`~/.claude/internship-brain/`

- internship/work experience,
- resume bullets,
- interview preparation,
- accomplishments,
- technical projects,
- architecture,
- technologies I used,
- difficult decisions,
- disagreements,
- feedback,
- debugging,
- failures,
- metrics,
- measurement methodology,
- production impact,

consult `~/.claude/internship-brain/INDEX.md` first and use the `internship-brain` skill for deeper retrieval.

When normal coding conversations reveal durable new information about my internship work, update the relevant evidence-bank files instead of letting the information disappear with the conversation.

Never invent metrics, ownership, disagreements, architecture rationale, or production impact.
